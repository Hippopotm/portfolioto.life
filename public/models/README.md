Place exported project models here as web-ready GLB or GLTF files.

The site automatically tries to load these files:

- `omniwheel-vehicle.stl` for the omniwheel room
- `welcome.glb` for the home room
- `snowboard.gltf` for the mountainboard room
- `swing.glb` for the children's swing room
- `tripod.glb` for the Devialet speaker tripod room
- `tripod-preview.glb` for the lightweight Devialet tripod preview
- `heating-bowl.glb` for the Heating Bowl SI14 room
- `heating-bowl-preview.glb` for the lightweight Heating Bowl SI14 preview
- `heating-sphere.gltf` for the Silicium 14 heating sphere room
- `lamp.glb`
- `hanger.glb`
- `cow.glb`

STEP/STP CAD files should be converted to GLB before the browser loads them. If you add the source STEP files to the workspace, they can be converted and placed here with the matching project filename.
